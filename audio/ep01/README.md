## Таймкоды

- `alignment.json` — начало и конец каждой строки сценария (из него собирается видео).
- `ep01_voiceover_full.srt` — субтитры по репликам для общего файла.
- `timecodes.csv` — каждая реплика: сцена, время в общем файле и внутри файла сцены.
  `confidence = pause` — реплика ограничена реальными паузами; `dip` — несколько реплик
  идут без паузы, граница поставлена в провал громкости.

Таймкоды получены без распознавания речи: `audio/tools/align.py` сопоставляет строки
с фрагментами речи между паузами по числу слогов.

## Не озвучено

Генерация упёрлась в лимит 5 000 символов: запись обрывается на «Потому что он знае…» (строка 223).
Нужно догенерировать строки 223–230 тем же голосом и с теми же настройками:

```
Потому что он знает, как всё началось.
Илья внезапно повернулся.
Его лицо стало совершенно спокойным.
Он посмотрел прямо на меня.
И сказал:
Я знаю, кто первым заразился.
Пауза.
И это был не человек.
```

«Пауза.» — ремарка, её не нужно читать вслух: в ElevenLabs вместо неё поставь `<break time="1.5s" />`.
