# Эпизод 2 — «Остров», видео

**`ep02_vertical.mp4`** — готовая серия: 9:16, 1080×1920, 30 к/с, 3:12.
Зомби-апокалипсис на необитаемом острове, пять правил выживания. Плоская графика в стиле
первой серии, живая анимация (персонажи дышат, моргают, двигаются; камера с наездами
и тряской; разные переходы), субтитры с подсветкой слов, звук под каждое действие.
В конце — заставка «Что у неё в левой руке? · Продолжение следует».

## Как собирается

```
python3 video/engine/build.py video/ep02 out.mp4            # вся серия
python3 video/engine/build.py video/ep02 out.mp4 --to 33    # только первые 33 секунды
```

- `episode.json` — где озвучка, разметка по словам и ключевые слова; длина серии.
- `scene1.js` — общая графика (остров, пальмы, обломки, кабина, рука, лежащий человек)
  и сцена 1: крушение, правило 1 (перелом).
- `scene2.js` — закат и холод, правило 2 (укрытие), рация, правила 3 и 4 (укусы, вода).
- `scene3.js` — постройка лагеря: шалаш «А», листья черепицей, пол, вход от ветра,
  верёвка с банками, «но было одно «но»».
- `scene4.js` — ночь, шаги, девушка у шалаша, правило 5, «Антон, прошу», заставка.
- `sound.py` — звук: озвучка + прибой, ветер, гул, сверчки + эффекты (самолёт, удар, всплеск,
  помехи, шаги по песку, банки, удары по дереву и т. д.). Синтез — в `../engine/sfx.py`.
- `timing.js`, `captions.js` — создаются при сборке из `audio/ep02/alignment.json`.

Сценария не было, поэтому текст распознан с озвучки офлайн (`audio/tools/transcribe.py`,
модель GigaAM) и выровнен по словам (`audio/tools/align_words.py`): каждое слово
субтитров и каждое действие на экране привязаны к моменту, когда оно звучит.
