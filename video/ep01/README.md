**`ep01_vertical.mp4`** — готовая серия: 9:16, 1080×1920, 30 к/с, 5:53.
Плоская рисованная графика по образцу, субтитры с подсветкой слов, заголовки-цитаты,

`ep01_chernovik.mp4` — первый черновик: только звук и текст на тёмном фоне.

## Как собирается

Все кадры рисуются кодом в браузере (Chromium через Playwright), звук синтезируется в Python.

```
python3 video/ep01/src/make.py out.mp4            # вся серия
python3 video/ep01/src/make.py out.mp4 --end 60   # только первая минута
```

- `../engine/` — движок: `render.js` (рендер кадров), `player.html`, `lib.js`, `flat.js`
  (палитра, персонажи, портреты, субтитры, заголовки, плашки).
- `flat/scene1.js` … `flat/scene6.js` — кадры по сценам; смена кадров привязана к строкам сценария.
- `../engine/captions.py` — делит реплики на короткие субтитры и выделяет ключевые слова.
- `../engine/sfx.py` — синтез звуковых эффектов и сведение (общие для всех серий).
- `src/sound.py` — звук: озвучка + эффекты + фон; `src/make.py` — сборка целиком.
- Тайминги строк берутся из `audio/ep01/alignment.json`.
